A one-image front page summing up the world news of Friday 20 November 2026: Russia's overnight barrage of Kyiv as the lead story, plus the Houthi missile strike on Riyadh, Trump's delayed Iran decision, the AI stock sell-off, the COP31 fossil-fuel draft, Estonia's border closure, the White House cyber chief's dismissal and the EU-UK Brussels summit. The picture is drawn with Pillow by `draw.py` (stories and sources in `SOURCES.md`), packed into `main.ts` by `pack.mjs`, and written out verbatim when the program runs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
